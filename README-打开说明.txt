航空动态个人简介 · 第一版预览

打开方式：双击本目录中的 index.html，推荐使用 Edge 或 Chrome。
请把 index.html 和 assets 文件夹放在一起；发送给别人时，发送完整文件夹或 ZIP。

本版内容：
1. 保留原个人简介的文字、经历、项目、证书、导航与联系方式。
2. 航空发动机背景固定覆盖整个页面，叠加持续推进镜头和流动气流轨迹。
3. 导航、成果栏及内容面板采用半透明玻璃样式，按钮使用深色渐变。
4. 手机导航支持侧滑、背景淡入、链接依次入场、Escape 关闭和滚动锁定。
5. 右上角可以暂停动效、切换明暗主题；系统开启减少动态效果时默认暂停。

实现说明：
参考链接的视频内容为森林场景，因此本版使用原有航空发动机图片制作本地动态场景。
采用原站 HTML/CSS/JavaScript 结构，未迁移 React，也未替换为 nexum 的商业文案。
背景使用 CSS 镜头动画与 Canvas 气流，不是实拍航空视频；素材已打包，本地无需下载视频即可播放动效。
Geist 字体通过参考指定的 Google Fonts 地址加载；不可访问时使用系统字体。
原始 D 盘文件没有改动。
